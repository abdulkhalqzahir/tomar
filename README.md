### 🎨 تایبەتمەندییە دیزاینییە هاوبەشەکان:
- **تەوەرەی دارایی و ژمێریاری (Emerald Slate Theme)**: ڕەنگی سەوزی درەوشاوەی بانکداری و دارایی لەگەڵ پاشبنەمای شین/تاریکی مۆدێرن.
- **Glassmorphism**: دیزاینی شووشەیی کاڵ بۆ هەموو کارت، بۆکس، و بەشەکان بە `backdrop-filter: blur(24px)`.
- **بۆکس شادۆی درەوشاوە (Glowing Box-Shadows)**: قووڵایی فرە-چین لەگەڵ ئیفێکتی نیۆنی نەرم.
- **هێڵی سکانەری درەوشاوە (Scanner Beam)**: لە سەرووی کارتەکاندا دەدرەوشێتەوە.
- **ئەنیمەیشنی 3D Tilt**: کارلێکی سێ ڕەهەندی لەگەڵ جووڵەی ماوس لە فۆرمی لۆگین.
- **بەستنەوەی تەواو**: دوای لۆگین لە `index.html` بە ئەنیمەیشن ڕاستەوخۆ دەچێتە سەر `zhmeryary.html`، و لەناو `zhmeryary.html` بەشی سەرەوە نیشاندەری ناوی مامۆستا عەبدولخالق و دوگمەی "دەرچوون"ی هەیە بۆ گەڕانەوە بۆ لۆگین.
